# PerdangaFactoryCalendar

[English version](README.en.md)

Настольное приложение для составления графиков работы: каждый день можно отметить как «День», «Ночь» или «Выходной». Праздники и переносы выходных подписаны по производственному календарю РФ.

## Возможности

- **Несколько графиков.** При первом запуске создаётся график «Мой график». Графики можно создавать, переименовывать и удалять. Удалить можно, только если графиков больше одного. Названия не повторяются без учёта регистра и не длиннее 40 символов.
- **Стандартный график 5/2.** Кнопка создаёт новый график «5/2 (стандартный)» на 2025–2027 годы по производственному календарю: суббота и воскресенье выходные, кроме рабочих суббот 1 ноября 2025 и 20 февраля 2027. Второй такой график создать нельзя.
- **Календарь по месяцам.** Неделя начинается с понедельника. Переключение месяцев кнопками ‹ и ›, возврат к текущему месяцу кнопкой «Сегодня».
- **Отметки дней.** Зажмите ЛКМ и протяните, чтобы выделить несколько дней. ПКМ открывает меню «День», «Ночь», «Выходной», «Очистить». Если нажать ПКМ на выделенном дне, действие применится ко всему выделению. Esc снимает выделение, если не открыто окно переименования.
- **Размножение цикла.** Кнопка «Размножить до конца года» повторяет выделенный шаблон из дней, ночей и выходных от следующего дня до конца года. Все дни выделения должны быть отмечены заранее. Перед перезаписью существующих отметок приложение спрашивает подтверждение.
- **Статистика за месяц.** Количество дневных, ночных и выходных дней и дней без отметки.
- **Праздники и переносы.** Подписаны в ячейках, полное название показывается во всплывающей подсказке. Переносы выходных есть только для 2025–2027 годов.

## Хранение данных

Изменения сохраняются сразу в файл `schedules.json` в папке данных приложения. В Windows это `%APPDATA%\ru.example.graphics\`.

- **Запись атомарная.** Данные пишутся во временный файл `schedules.json.tmp`, затем он заменяет основной. Обрыв записи не портит предыдущее состояние.
- **Изменение только после записи.** Если сохранить не удалось, приложение показывает ошибку, и изменение не появляется в интерфейсе.
- **Повреждённый файл.** Если файл не разбирается или в нём нет ни одного графика, он переименовывается в `schedules.broken.json`, и приложение запускается с новым графиком «Мой график». Если `schedules.broken.json` уже есть, новая копия получает имя `schedules.broken-<время>-<номер>.json`, а старая не трогается.
- **Файл, который не удалось прочитать** (нет доступа, занят другой программой), не переименовывается и не перезаписывается. Приложение показывает ошибку, и все изменения отключены, пока файл не будет исправлен или приложение не перезапустится.

## Стек

- [Tauri 2](https://tauri.app/): оболочка приложения. Логика написана на Rust, интерфейс выводится в WebView2.
- Интерфейс: HTML, CSS и JavaScript без фреймворков и сборщика.
- Rust-библиотеки: chrono (работа с датами), serde и serde_json (сохранение данных).

## Структура проекта

```
.
├── src/                  интерфейс: index.html, main.js, styles.css
└── src-tauri/
    ├── src/
    │   ├── lib.rs        графики, производственный календарь, команды Tauri, тесты
    │   └── main.rs       точка входа
    ├── capabilities/     права окна
    ├── icons/            иконки приложения
    └── tauri.conf.json   настройки Tauri
```

## Запуск для разработки

Понадобятся:

- [Node.js](https://nodejs.org/) (LTS) с npm
- [Rust](https://www.rust-lang.org/tools/install) через rustup
- Зависимости Tauri для Windows: Microsoft C++ Build Tools с компонентом «Разработка классических приложений на C++» и WebView2. Подробнее: https://tauri.app/start/prerequisites/

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Установщики появятся в `src-tauri/target/release/bundle/`: MSI в папке `msi/` и установщик `.exe` в папке `nsis/`.

## Тесты

```bash
cd src-tauri
cargo test
```

## Производственный календарь

Выходные дни, переносы и рабочие субботы для стандартного графика хранятся в константе `CALENDARS` в `src-tauri/src/lib.rs`. Чтобы добавить новый год, внесите его туда.
